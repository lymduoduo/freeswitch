# 每周复盘 / Weekly Review

## 复盘目的 / Purpose

每周花 30 分钟做一次内容运营复盘，确保：
1. 了解什么内容有效、什么无效
2. 保持内容发布节奏
3. 迭代优化策略
4. 管理内容 Backlog

## 月度汇总触发器 / Monthly Rollup Triggers

每月第一个周复盘时，额外完成：
- [ ] 更新 `ops/publishing-calendar.md` 中的内容归档表
- [ ] 运行 `prompts/topic-generator.md` 补充下月 Backlog
- [ ] 对 Backlog 中所有话题用 `ops/content-scorecard.md` 重新评分
- [ ] 检查 `strategy/monetization.md` 中的阶段目标进度
- [ ] 更新受众增长数据（`strategy/audience.md` 增长追踪部分）
