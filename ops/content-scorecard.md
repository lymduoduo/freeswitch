# 内容评分卡 / Content Scorecard

## 评分系统说明 / How to Use

在将话题加入发布日历之前，用此评分卡评估每个内容想法。
总分 ≥ 70 → 优先发布；50–69 → 下月备选；< 50 → 暂存或放弃。

---

## 评分维度 / Scoring Dimensions (Total: 100 points)

### 1. 受众相关性 / Audience Relevance (25 pts)
> 目标受众会真正需要或渴望读这个内容吗？

| 分数 | 标准 |
|------|------|
| 25 | 解决我的目标受众每周都会遇到的具体问题 |
| 20 | 解决常见但非每日的痛点 |
| 15 | 相关但非紧迫的话题 |
| 10 | 边缘相关，受众可能感兴趣 |
| 5  | 主要是我感兴趣，受众可能不关心 |

### 2. 独特性 / Uniqueness (20 pts)
> 这个内容角度在网上已经被说烂了吗？

| 分数 | 标准 |
|------|------|
| 20 | 完全新颖的视角，搜索不到类似内容 |
| 15 | 有独特切入点，但相关话题存在 |
| 10 | 改进版本的已有内容（更深/更新/更实用） |
| 5  | 类似内容已有很多，差异不大 |
| 0  | 已经被说烂了 |

### 3. 我的专业权威性 / My Authority (20 pts)
> 我有第一手经验或独特视角来写这个吗？

| 分数 | 标准 |
|------|------|
| 20 | 基于真实项目经验，我踩过这个坑 |
| 15 | 研究深入，有具体实验或测试支撑 |
| 10 | 理解原理，但没有亲身实践 |
| 5  | 二手知识，主要靠整合 |
| 0  | 我对这个领域没有特别了解 |

### 4. 搜索/发现潜力 / Discoverability (15 pts)
> 人们会主动搜索这个内容吗？

| 分数 | 标准 |
|------|------|
| 15 | 高搜索量关键词 + 现有结果质量差 |
| 10 | 有搜索量，竞争适中 |
| 5  | 小众关键词，但精准 |
| 0  | 无搜索量，仅靠社交传播 |

### 5. 常青价值 / Evergreen Value (10 pts)
> 这个内容 2 年后还有价值吗？

| 分数 | 标准 |
|------|------|
| 10 | 基础原理类内容，长期有效 |
| 7  | 工具/框架相关，可能需要更新但基本稳定 |
| 4  | 某个版本/时期特定，有效期 1 年左右 |
| 0  | 新闻性内容，几周后过时 |

### 6. 可重用性 / Repurposability (10 pts)
> 这个内容能衍生出几个其他格式的内容？

| 分数 | 标准 |
|------|------|
| 10 | 能衍生出：文章 + 线程 + LinkedIn + Newsletter + 课程模块 |
| 7  | 能衍生出 3 种格式 |
| 4  | 能衍生出 2 种格式 |
| 1  | 只适合一种格式 |
