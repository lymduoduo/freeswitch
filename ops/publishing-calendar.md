## 发布检查清单 / Pre-publish Checklist

### 文章发布前
- [ ] 使用 `prompts/editor-review.md` 完成编辑审查
- [ ] 代码示例已测试运行
- [ ] 标题已 A/B 测试（至少想了 3 个版本）
- [ ] Meta description 已写好（< 160 字符）
- [ ] 内部链接已添加（链接相关旧文章）
- [ ] 配图/架构图已准备（如需要）
- [ ] 社交媒体推广文案已准备

### 发布后操作
- [ ] 在 Twitter/X 发布推广线程
- [ ] 在 LinkedIn 发布推广帖
- [ ] 在 Newsletter 中提及（当周期）
- [ ] 回复前 24 小时内的评论
- [ ] 7 天后记录初始指标
