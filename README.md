# Tech Personal Brand System

A complete operating system for building a technical personal brand as a Go backend engineer
specializing in FreeSWITCH, SIP/RTP, call-center systems, and AI voice-agent architecture.

## Repository Structure

```
tech-personal-brand-system/
├── strategy/          # Brand positioning, audience, pillars, voice, monetization
├── knowledge/         # Research notes, reference docs, competitor analysis
├── content/           # Drafts, published pieces, ideas
├── prompts/           # AI prompts for content creation workflow
├── assets/            # Images, diagrams, brand assets
├── distribution/      # Platform-specific publishing configs and templates
├── products/          # Course outlines, tool specs, paid product drafts
└── ops/               # Publishing calendar, scorecards, weekly reviews
```

## Quick Start

### 1. Define your foundation (start here)
- [ ] Read and customize `strategy/positioning.md`
- [ ] Fill in your specific audience details in `strategy/audience.md`
- [ ] Review content pillars in `strategy/content-pillars.md`
- [ ] Internalize your voice rules in `strategy/brand-voice.md`

### 2. Generate your first content batch
- [ ] Use `prompts/topic-generator.md` to generate 20 topic ideas
- [ ] Score each with `ops/content-scorecard.md`
- [ ] Plan the top 8 into `ops/publishing-calendar.md`

### 3. Write and publish
- [ ] Draft with `prompts/article-writer.md` or `prompts/thread-writer.md`
- [ ] Review with `prompts/editor-review.md`
- [ ] Repurpose with `prompts/repurpose.md`

### 4. Operate weekly
- [ ] Every Friday: 30-min review using `ops/weekly-review.md`
